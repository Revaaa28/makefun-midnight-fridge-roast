## The line

> After midnight the fridge only opens for 'authorized users.' I live alone. The fridge has never said who they are.

## How it works

`main.py` writes the line to `/output/entry.txt`; nothing else runs. The script is Python 3, standard library only, and it refuses to write if the line is blank or longer than 200 characters.

## How the line was chosen

Ten candidates were ranked by hand against the judge brief in the brief's own order — see [candidates.md](candidates.md). The winning line was picked because the midnight refusal rule itself is the joke, the 'authorized users' angle is specific to a smart fridge, and the final sentence lands as a genuine twist in one tight breath.
